# Support

Thanks for using our projects. This document explains where to get help.

## Support Channels

Please use the channel that best fits your need:

- **GitHub Issues**: For reproducible bugs or specific feature requests,
  open an issue in the relevant repository's issue tracker. Please search
  existing issues first to avoid duplicates.
- **Email**: For questions that do not fit a public channel, contact us at
  <support@massimoselvi.com>.

For security vulnerabilities, do **not** use the channels above. Follow the
private disclosure process described in [SECURITY.md](https://github.com/Cell-V/.github/blob/main/SECURITY.md).

## Before Reaching Out

To help us respond faster, please include the following when relevant:

- A clear description of the problem or question
- Steps to reproduce, along with expected and actual behavior
- The version of the project you are using
- Any relevant logs, error messages, or screenshots

## Contributing

If you would like to contribute a fix or improvement, see our
[Contributing Guidelines](https://github.com/Cell-V/.github/blob/main/CONTRIBUTING.md).
